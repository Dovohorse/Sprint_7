# Sprint_7

# Автотесты для API сервиса «Яндекс Самокат»

Проект для 7 спринта курса QA Engineer.  
Набор API-тестов для сервиса оформления доставки самокатов.

Тесты покрывают базовые сценарии работы курьеров и заказов.

## Стек

- Python 3.x
- `pytest`
- `requests`
- `allure-pytest`

## Структура проекта

- `data/`
  - `urls.py` — базовый URL стенда и пути к ручкам API
  - `orders_payloads.py` — шаблоны тел запросов для создания заказа
- `helpers/`
  - `generator.py` — генерация случайных данных (логин/пароль/имя курьера)
- `tests/`
  - `test_courier_create.py` — тесты для ручки **создания курьера**
  - `test_courier_login.py` — тесты для **логина курьера**
  - `test_courier_delete.py` — тесты для **удаления курьера**
  - `test_orders_create.py` — тесты для **создания заказа**
  - `test_orders_list.py` — тесты для **получения списка заказов**
  - `test_order_accept.py` — тесты для **принятия заказа курьером**
  - `test_order_by_track.py` — тесты для **получения заказа по номеру (track)**
- `conftest.py` — фикстуры `http` (HTTP-сессия) и `courier` (создание и удаление тестового курьера)
- `requirements.txt` — зависимости проекта
- `allure_report/` — сгенерированный Allure-отчёт (статические файлы)
